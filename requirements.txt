# The Mac app runs on macOS 12 (Monterey) or later, the newest system many
# 2015-2017 Macs can install. Each Mac pin below is the newest version whose
# binaries really load there: wheel tags can understate what a binary needs, so
# this was read from the binaries themselves (their LC_BUILD_VERSION), and
# build_mac.sh checks every bundled binary again. The Mac environment is also
# installed from wheels built for macOS 12 only (see build_mac.sh), or pip would
# take numpy's macOS 14 wheels on a newer machine.
